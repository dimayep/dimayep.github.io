# Dmitriy's Notes

A deliberately simple personal blog hosted with GitHub Pages.

## Structure

- `index.html` — homepage and article list
- `about.html` — about page
- `posts/` — individual articles
- `assets/style.css` — all visual styling

There is no database, framework, tracking script, or hidden content system. Every published page is an ordinary text file.

## Adding an article

1. Add a new HTML file under `posts/`.
2. Add its title, date, summary, and link to `index.html`.
3. Commit the changes to `main`.

GitHub Pages then publishes the updated files.
